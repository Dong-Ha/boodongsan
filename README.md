# boodongsan — 처음 배우는 부동산

서울·경기의 주거용 부동산을 처음 공부하는 사람을 위한 한국어 학습 노트입니다. 용어를 이해하고, 내 자금으로 가능한 선택을 계산하고, 집과 계약을 비교하는 능력을 차례로 익힙니다.

**처음에는 [0강: 오늘 시작하기](lessons/00-start-here.md)를 읽으세요.** 이어서 [8주 학습 계획](ROADMAP.md)을 따라가면 됩니다. 주 3회, 회당 30~40분을 기본으로 하되 진도보다 실습 결과를 우선합니다.

## 읽는 원칙

개념은 반복해서 익히고, **대출 한도·세율·청약 자격은 해당 시점의 공식 원문으로 확인**합니다. 발표 예정, 발표 완료, 시행 중인 제도를 구분합니다. 오래된 공식 자료도 현재 규정의 근거로 쓰지 않습니다.

실습 결과에는 조회일·지역·면적·기간·출처를 함께 적습니다. 개인 소득, 보유 자산, 계좌 정보, 계약 상대방 정보는 공개 저장소에 기록하지 않고 가상값이나 익명화한 값으로 연습합니다.
