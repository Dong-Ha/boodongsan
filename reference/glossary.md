# 입문 용어 사전

[전체 순서](../README.md) · [공식 출처](../sources/catalog.md)

처음부터 외우지 않습니다. 강의와 매물을 보다가 모르는 단어가 나오면 찾아봅니다. 법률·금융의 실제 적용은 공식 원문과 조건을 확인합니다.

| 용어 | 쉬운 뜻 | 연결 강의 |

| 공급면적 | 전용면적 + 주거공용면적 | 1강 |
