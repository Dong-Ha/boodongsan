# 6강 — 입지와 현장 확인

[이전: 5강](05-data-and-market.md) · [전체 순서](../README.md) · [다음: 7강](07-seoul-gyeonggi.md)

## 목표

집의 위치와 상태를 **내 생활에 연결되는 조건**으로 비교합니다.

## 쉬운 설명

입지는 위치의 장단점입니다. 같은 역 근처라도 집에서 승강장까지 가는 길, 환승 횟수, 경사와 소음에 따라 생활이 달라집니다. 지도상의 거리와 실제 이동 경험을 함께 확인합니다.

| 기준 | 기록할 것 | 확인 방법 |
|---|---|---|
| 출퇴근 | 집 문부터 목적지까지의 시간·환승·비용 | 같은 시간대 경로 확인, 직접 이동 |
| 생활 | 장보기·병원·공원·필요 시설 | 운영 시간과 실제 접근 동선 |
| 교육 | 필요 시 통학 동선·배정 정보 | 학교·교육청의 공식 안내 |
| 주거 환경 | 소음·일조·냄새·경사·주차 | 낮·저녁 등 시간대를 바꿔 방문 |
| 단지 상태 | 연식·동 배치·승강기·유지관리 | 현장과 공개 단지 자료 |
| 집 상태 | 누수·곰팡이·설비·채광·수리 범위 | 방문 확인과 관련 증빙 |
| 관리비 | 공용관리비·사용료·난방 차이 | 같은 면적·같은 월의 내역 비교 |

**임장**은 현장에 가서 살펴보는 일입니다. 대단한 투자 기술을 뜻하는 말이 아니라 지도와 광고에서 모르는 것을 직접 확인하는 과정으로 생각하세요.

## 가상 사례: 역까지 5분인데 출퇴근이 더 길다

가상 A단지는 집→역 5분, 대기·승차·환승·목적지 도보 50분으로 총 55분입니다. B단지는 집→역 12분, 나머지 30분으로 총 42분입니다. 역과의 도보 거리만 보면 A가 가깝지만 목적지까지는 B가 빠릅니다.

필요한 조건을 `필수·선호·포기 가능`으로 나누세요. 예를 들어 출퇴근 60분 이하를 필수로 정했다면 다른 점수가 높아도 그 조건을 넘는 집은 별도로 보류합니다.

## 개발 계획 읽는 방법

새 역·재개발·재건축 이야기는 **검토, 공식 계획, 인허가, 착공, 운영·입주** 중 어디까지 진행됐는지 확인합니다. 이 구분은 여러 사업에 공통으로 질문할 틀이며 사업마다 법정 절차는 다릅니다. 재건축·재개발의 비용과 분담금은 추가 학습 주제입니다.

완료되기 전의 효과를 이미 있는 교통·생활 환경과 섞지 않습니다. 계획의 출처와 확인 날짜, 예상 시점이 바뀔 가능성을 적습니다. 사업 진행과 투자 수익은 같은 판단이 아닙니다.

## 실습

1. [현장 방문 양식](../templates/site-visit.md)을 복사합니다.
2. 관심 단지 한 곳의 주변을 방문해 역·버스·마트까지 실제 시간을 기록합니다.
3. 집 내부 확인은 방문 약속과 출입 허용이 있는 경우 진행합니다. 외부만 봤다면 내부 항목은 `미확인`으로 적습니다.
4. [K-apt](https://www.k-apt.go.kr/)에서 공개 대상 단지의 관리비와 단지 정보를 확인합니다. 사용자별 전기·수도 등 사용료와 공용 비용을 구분합니다.
5. 현장에서 확인한 사실 3개와 아직 모르는 것 3개를 적습니다.

## 확인 문제

1. 역세권이라는 표현만으로 출퇴근 시간이 짧다고 할 수 있나요?
2. 관리비 20만원과 30만원을 비교할 때 무엇을 맞춰야 하나요?
3. 신규 노선이 검토 중이라면 개통된 노선과 똑같이 평가해도 되나요?

<details>
<summary>해설</summary>

1. 전체 경로·대기·환승·시간대를 확인합니다.
2. 면적·계절·공용 비용·사용료·난방 방식과 포함 항목을 맞춥니다.
3. 현재 이동 편의와 미래 계획을 별도로 기록합니다.
