# 0강 — 오늘은 매물 하나를 읽어보기

[전체 순서](../README.md) · [다음: 1강](01-basics.md)

## 목표

오늘은 부동산을 전부 이해할 필요가 없습니다. **집을 보고 어떤 질문을 해야 하는지** 익히는 것부터 시작합니다.

## 쉬운 설명

집을 고르는 일에는 세 가지가 함께 들어 있습니다. 살기 편한지, 돈을 감당할 수 있는지, 계약상 문제가 없는지입니다. 가격만 보면 나머지 두 가지를 놓칠 수 있습니다.

스마트폰을 살 때도 가격 외에 크기, 배터리, 보증을 봅니다. 집에서는 그 항목이 면적, 위치, 관리 상태, 권리와 자금으로 늘어납니다.

## 오늘 30분 실습

1. 익숙한 서울·경기 생활권 1곳을 정합니다. 집·직장·자주 가는 역 주변이면 충분합니다.
2. 지도나 매물 서비스에서 단지 1개와 매물 1개를 봅니다. 광고 가격은 **호가**로 기록합니다.
3. 아래 다섯 가지를 적습니다. 모르는 것은 `미확인`이라고 씁니다.

| 항목 | 기록 |
|---|---|
| 단지 이름과 시·구/군·동 |  |
| 매매·전세·월세 중 무엇인가 |  |
| 가격 또는 보증금·월세 |  |
| 전용면적·공급면적 |  |
| 확인 날짜와 출처 URL |  |

4. 이 집에 대해 궁금한 것 3개를 씁니다. 예: 실제 계약 가격은? 출퇴근은? 관리비는?
5. [1강](01-basics.md)을 읽고 위 기록에서 잘못 이해한 것을 수정합니다.

## 가상 사례

`가상 A단지 / 전용 59㎡ / 전세 3억원`은 집을 3억원에 산다는 뜻이 아닙니다. 계약 기간 동안 거주하고 나중에 돌려받을 보증금이 3억원이라는 뜻입니다. 돈을 돌려받을 조건과 집주인의 상태를 확인하는 것은 4강에서 배웁니다.

## 확인 문제

1. 매물에 7억원이라고 쓰여 있으면 실제로 거래된 가격인가요?
2. 오늘 기록하지 않아도 되는 것은 무엇인가요: 면적, 거래 형태, 10년 뒤 예상 가격?

<details>
<summary>해설</summary>

1. 광고된 매도 희망 가격일 수 있습니다. 실제 계약 가격은 실거래 자료에서 따로 확인합니다.
2. 10년 뒤 예상 가격입니다. 첫날에는 지금 확인할 수 있는 정보의 구분부터 익힙니다.

</details>
